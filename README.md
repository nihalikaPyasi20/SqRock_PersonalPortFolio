# Personal Portfolio Website

A modern and responsive personal portfolio website built using HTML, CSS, and JavaScript to showcase my skills, projects, education, resume, and contact information.

## ✨ Features

- Responsive and mobile-friendly design
- Clean and modern user interface
- Smooth scrolling navigation
- Mobile navigation menu
- Active navigation link highlighting
- About Me section
- Technical and soft skills section
- Projects showcase
- Resume download option
- Education and achievements section
- Contact information and social media links
- Contact form
- Hover effects and animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Git & GitHub
